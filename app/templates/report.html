Jede der {{ H.questions }} Fragen wurde am {{ R.date|date }} einmal an jedes der fünf KI-Modelle und an eine Websuche gestellt. Die Websuche ist eine unabhängige Suche und steht als Annäherung, nicht für Google.

Als Treffer zählt eine Antwort, wenn sie {{ name }} in einer der hinterlegten Schreibweisen ({{ R.site.aliases_list|join(', ') if R.site.aliases_list else name }}) oder die Domain nennt. Bei der Websuche zählt, ob {{ R.site.domain }} unter den ersten zehn Treffern steht. Die Fragen wurden aus dem Inhalt der Website abgeleitet und bleiben von Prüfung zu Prüfung gleich, solange sie nicht ausdrücklich geändert werden.
